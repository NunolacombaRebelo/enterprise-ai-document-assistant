# ADR 0003 — Use uv for Python dependency management

## Status
Accepted (Phase 0)

## Context
We need reproducible, fast, cross-platform dependency management that does not rely on global pip
installs and works identically on Windows and Linux. The lockfile must be generated by a real
resolver, never hand-edited.

## Decision
Use **uv** for all dependency management. `pyproject.toml` declares dependencies; `uv.lock` is the
generated lockfile; `uv sync --locked` installs the exact locked versions into the project `.venv/`.
Python 3.12 is selected via `.python-version`.

## Consequences
- Positive: fast resolution, single tool for venv + deps + Python version, reproducible installs,
  portable across OS.
- Negative: developers must install uv (documented in `docs/development.md`).
- Only Agent 1 modifies `pyproject.toml` / `uv.lock`.
